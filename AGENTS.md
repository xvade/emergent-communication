This repository is divided into a human managed section and an agent managed section. You may only edit files in the `/agents` directory. You may still read files in the human portion.

Check the host machine before starting work. If you're on klone, that's UW's HPC.

## Tips/rules for using klone
- `~` has only 10 gigs of space.
- You may be on a login node. While you are **do not use subagents**, the limited compute means that they will crash the process. If you want to use a subagent, just allocate some compute for it.
- You can allocate compute using slurm.
